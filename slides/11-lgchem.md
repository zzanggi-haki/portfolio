## 문제 정의

고객은 이미 목표(적시생산 Agent)와 데이터(Excel backbone)를 가지고 있었습니다. 고객 미팅 2회와 요구 메일을 제안 단계에서 먼저 구조화(AX Goal 재정의, 데이터 흐름, 미확정 요소 3가지)해, 부족한 것은 **SCM 담당자와 고참의 판단 로직**이라고 진단했습니다.

## 리서치가 만든 결정

고객이 이미 목표(적시생산 Agent)와 데이터(Excel backbone)를 가지고 있어, 제안의 중심을 기능 스펙이 아니라 SCM 담당자와 고참의 판단 로직을 꺼내는 Discover 단계에 두었습니다. 그 결과물(업무 흐름 7단계·Painpoint)이 그대로 AI 에이전트 5종과 1차 구축 범위로 이어지도록 설계했습니다.

## 어떻게 했나

- Discover: 파트별 담당자 최소 2명×풀데이 관찰-인터뷰 (IDI · Walkthrough · Contextual Inquiry) + 15~20문항 AI Pre-interview bot → 액션 단위 Workflow Mapping → AX 브리프
- Define→Develop: Problem Statement → Orchestrator Agent 컨셉 → 1차 Scope → Agent 5종(Production · Sales · Scheduling Orchestrator · Profit Scoring · Monitoring)
- Claude로 가상 데이터 기반 프로토타입 v0.1~0.3을 제작해, 구축 범위를 화면으로 협의하도록 설계
