## 프로젝트 배경

AI 학습 데이터 라벨링 툴 'STUDIO'의 PO로서, 라벨링 작업자와 검수자가 사용하는 전체 워크플로우의 핵심 병목을 해소하기 위해 진행한 개선 과제. '검수' 단계는 데이터셋의 퀄리티를 책임지는 과정으로, 검수자는 썸네일 뷰어에서 작업물의 오류를 확인합니다.

## 문제

기존 뷰어는 작업 결과물을 한 눈에 보는 단방향 도구였습니다. 검수 중 수정이 필요하면 뷰어를 벗어나 별도 경로로 요청을 전달해야 했고, 작업자는 다시 라벨링 작업 화면으로 돌아가 수정한 뒤 재제출해야 했습니다 — **검수→수정→재검수 사이클 전체 처리량 저하, 컨텍스트 스위칭, 수정 결과 즉시 확인 불가.**
